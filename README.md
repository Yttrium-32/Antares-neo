# Antares Neo
A simple weather and system monitor widget based on the now deleted ANTARES
conky theme by Closebox73. Adapted from my conky theme
[here](https://github.com/Yttrium-32/dotfiles/tree/main/dot-config/conky).

## Setup
1. Install Weather Icons font: https://erikflowers.github.io/weather-icons/
2. Install the Metropolis font: https://www.1001fonts.com/metropolis-font.html
2. Get your API key and city ID from open weather maps: https://openweathermap.org/
3. Create `.env` file as follows:
```
API_KEY=<api-key>
CITY_ID=<city-code>
```
